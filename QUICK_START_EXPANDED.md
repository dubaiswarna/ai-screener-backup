## **TROUBLESHOOTING:**

### **Problem: Data download fails**
**Solution:**
- Check internet connection
- Run `FETCH_EXPANDED_DATA.bat` again
- Failed stocks listed in: `data/stocks_all/failed_stocks.txt`

### **Problem: System slow**
**Solution:**
- Reduce batch size in config
- Close other programs
- Use cache (enabled by default)

### **Problem: No signals**
**Solution:**
- Check if data is downloaded
- Verify 700+ CSV files in `data/stocks_all/`
- Lower confidence threshold (70% → 65%)
