### **What is a PIP?**
```
PIP = Point in Percentage = Smallest price movement

For EUR/USD:
1.1525 → 1.1575 = 50 pips profit
1.1525 → 1.1500 = 25 pips stop

Pip Value:
Standard Lot (100,000): 1 pip = $10
Mini Lot (10,000): 1 pip = $1
Micro Lot (1,000): 1 pip = $0.10
```
